# Legislative System

# Web-Based Legislative Research, Policy Analysis, and Impact Evaluation System

The "Legislative System" is a web-based capstone project developed to support legislative research, policy analysis, and impact evaluation. The system is designed for academic purposes and is intended to serve as a proposed solution for an LGU setting in Manila City Hall.

The system aims to reduce manual work when managing legislative documents, researching policies, and evaluating their possible impacts. It also includes AI-assisted features to help users summarize information, identify relevant details, and support decision-making.

> Note: This project is developed for "capstone and academic purposes only". It is not an official system of Manila City Hall and is not intended to represent an actual government-deployed system.

# Features

- Legislative Document Management
- Legislative Research
- Policy Analysis
- Impact Evaluation
- AI-Assisted Analytics
- Intelligent Decision Support
- Policy Comparison
- Reports and Analytics
- User Management
- Audit Logs
- Public Ordinance Viewing

# Purpose of the System

The system aims to:

- Organize legislative documents in one platform
- Make legislative information easier to search and access
- Reduce time spent on manual policy analysis
- Support policy and impact evaluation
- Provide AI-assisted summaries and insights
- Help users make informed decisions based on available information
- Improve the overall efficiency of legislative research

# System Users in Administrator
The administrator can:

- Manage users
- Manage legislative records
- Manage research data
- Manage evaluations
- View reports and analytics
- Monitor system activities
- Manage system information

# Legislative Researcher / User
Users can:

- Search legislative documents
- Conduct legislative research
- Review policy information
- Perform policy analysis
- Evaluate policy impacts
- Use AI-assisted analytics
- Generate and view reports

# Project Scope

The system focuses on legislative research, policy analysis, impact evaluation, document management, and AI-assisted decision support.

The system does **not** automatically approve, reject, or create ordinances. Final decisions remain under the responsibility of authorized personnel.


# Development

This project was developed as part of a **Bachelor of Science in Information Technology (BSIT) Capstone Project**.

The development follows an **Agile Scrum methodology**, allowing the system to be developed and improved through iterative development, testing, and review.
